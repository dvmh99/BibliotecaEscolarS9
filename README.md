# BibliotecaEscolarS9

Sistema de gestión de biblioteca escolar desarrollado en Java para EFT de DOO II.

## Funcionalidades
- Inicio de sesión con roles de bibliotecario y estudiante.
- Gestión de libros, categorías, estudiantes y usuarios.
- Registro de préstamos y devoluciones.
- Control de stock y detección de atrasos.
- Reportes de préstamos e historial.

## Tecnologías
- Java y Swing
- MySQL y JDBC
- Patrones MVC, DAO y Singleton
- Hilos y sincronización

## Ejecución
1. Ejecutar los scripts SQL en MYSQL Workbench.
2. Configurar la conexión a la base de datos.
3. Abrir el proyecto en IntelliJ IDEA.
4. Ejecutar Main.java o JAR.
